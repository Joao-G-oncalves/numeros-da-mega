# 🎲 Números da Mega

Este projeto gera combinações aleatórias de números para a Mega-Sena, utilizando lógica simples em Python.  
Foi criado como exercício prático para aplicar conceitos de programação e manipulação de dados.

## 🚀 Funcionalidades
- Geração automática de 6 números aleatórios entre 1 e 60.
- Evita repetições dentro da mesma combinação.
- Possibilidade de gerar múltiplos jogos em sequência.

## 🛠️ Tecnologias utilizadas
- **Python 3**
- Biblioteca padrão `random`

## 📂 Como executar
Clone este repositório, acesse a pasta e execute o script:
```bash
git clone https://github.com/Joao-G-oncalves/numeros-da-mega.git
cd numeros-da-mega
python mega.py
```


## 🎯 Objetivo
Este projeto demonstra:
- Uso de funções e lógica de programação.
- Manipulação de listas e geração de números aleatórios.
- Estruturação de código simples e reutilizável.
